# v0.9.70 inventory scarcity handoff

This build adds inventory-scarcity intelligence on top of the existing price-history, anomaly, resale, economics and clearance-lifecycle layers.

## Added
- `lib/inventory-scarcity.js`: scores sellout/wait risk using on-hand observations, depletion, observation age, source confidence, pickup confirmation and clearance lifecycle.
- `lib/inventory-scarcity-alert.js`: can escalate an already-eligible standard alert to instant when fresh confirmed inventory is rapidly disappearing, but can never create an alert from an ineligible base opportunity; stale/weak inventory can downgrade urgency and unavailable inventory suppresses alerts.
- `db/050_inventory_scarcity_assessments.sql`: audit persistence for scarcity decisions.
- Regression tests for abundant, scarce, stale and unavailable inventory plus alert escalation/fail-closed behavior.
- PWA offline cache `huntiq-public-v81` includes both scarcity modules.
- Package version `0.9.70`.

## Product rule
Inventory urgency is separate from economic quality. Scarcity may change *when* HUNTIQ recommends acting, but it must not turn a weak/unprofitable opportunity into a BUY or manufacture alert eligibility. Inventory remains a timestamped confidence-bearing observation, never a guarantee.

## Retailer research added
`docs/ikea-retailer-fit-2026-09-03.md` records IKEA's public low-stock definition, store/online inventory separation, first-come/first-served behavior, Click & Collect caveats and deferred IKEA Family reward treatment.
