# HUNTIQ public retailer research — 2026-08-30

## Home Depot

Current Home Depot public guidance supports HUNTIQ's store-specific verification model:

- Home Depot's price-check guidance says shoppers should select a local store to see the correct local price and availability.
- Home Depot states online and in-store pricing can intentionally differ because of local pricing, promotions, and inventory conditions.
- Home Depot site footers continue to state that local store prices may vary and that displayed availability does not guarantee inventory.
- Home Depot's current price-match policy excludes clearance and closeout items. HUNTIQ must therefore treat a clearance observation as store-specific evidence, not as a portable price that another store is expected to honor.

Implementation consequence: continue storing `retailer + sku + storeId + observedAt + price + inventory + provenance`, require fresh re-verification before high-priority alerts, and never imply inventory certainty.

Sources checked 2026-08-30:
- https://www.homedepot.com/c/price-match-and-price-check
- https://www.homedepot.com/c/view-directory

## Best Buy

Best Buy's current developer catalog still exposes Products, Stores and Buying Options APIs. Products includes pricing, availability and product attributes, with most pricing updated near real time; Stores can be combined with Products for in-store availability; Buying Options exposes Open Box condition and reduced prices.

However, Best Buy's published API terms materially constrain HUNTIQ's use: API access requires a developer account/key; API Content may only be cached temporarily for up to 72 hours; and the terms include restrictions around using the service/content for third-party analysis of Best Buy pricing/products/services. The operational policy currently lists 50,000 calls/day and 5 calls/second for Products/Stores/Buying Options.

Implementation consequence: the adapter can be built and tested against fixtures now, but HUNTIQ must **not** treat Best Buy API Content as an unrestricted permanent price-history feed. Before production use, the actual HUNTIQ use case needs to be checked against/authorized under Best Buy's developer terms. Long-term historical signals should be designed so restricted source content can expire without corrupting derived models.

Sources checked 2026-08-30:
- https://developer.bestbuy.com/apis
- https://developer.bestbuy.com/legal

## Walmart

Walmart's current Item Search API can search the Walmart catalog by keyword and identifiers including UPC/GTIN, with a May 7, 2026 update adding ASIN support for US spec-format searches. The documented endpoint is part of the Walmart Marketplace developer platform and is framed around seller item setup/catalog workflows rather than as an unrestricted consumer retail-price feed. Search results also omit unpublished items, including out-of-stock items.

Implementation consequence: Walmart's Marketplace Item Search is useful for **identity resolution and catalog matching** in an authorized seller integration, but HUNTIQ should not assume it is a public store-price/inventory source. Keep Walmart catalog identity separate from store-level price observations, and do not build the anomaly engine around Marketplace availability semantics. A production Walmart connector should require explicit authorization/terms review before using seller APIs.

Sources checked 2026-08-30:
- https://developer.walmart.com/us-marketplace/reference/getsearchresult
- https://developer.walmart.com/us-marketplace/page/update-item-search-api-supports-spec-format-responses
- https://developer.walmart.com/us-marketplace/changelog/may-7-2026-release

## eBay

eBay's Browse API supports listing search by keyword, category, GTIN and product identifiers and requires an Application access token. Application tokens use the client-credentials flow and therefore do not require an end user's eBay account authorization for ordinary Browse searches, but an eBay developer account and application credentials are still required.

Implementation consequence: build/test the resale adapter with fixtures now. When credentials are available, use application-level OAuth for public listing search. Keep user-token flows out of the pilot unless a future feature genuinely needs user-owned data.

Sources checked 2026-08-30:
- https://developer.ebay.com/develop/api/buy/browse_api
- https://developer.ebay.com/api-docs/static/oauth-credentials.html
- https://www.developer.ebay.com/support/faq

## Costco

Costco Same-Day publicly states that its delivery prices are marked up above local warehouse prices. That means Costco.com/Same-Day observations should not be treated as direct warehouse-price proxies in HUNTIQ.

Costco customer service also states, in a document published 2026-03-03, that Costco does not price match other retailers.

Implementation consequence: if Costco is added later, HUNTIQ should distinguish warehouse, Costco.com, and Same-Day/Instacart observations as separate channels and avoid comparing them as if they were the same shelf price.

Sources checked 2026-08-30:
- https://sameday.costco.com/store/costco/pages/pricing-policy
- https://customerservice.costco.com/app/answers/answer_view/a_id/1162/~/does-costco-price-match-with-other-retailers%3F

## Tractor Supply

Tractor Supply's Terms of Use were last updated February 19, 2026 and explicitly say that Site prices may vary across geographic markets and between the website and physical stores. Its current price-match policy also excludes clearance items, close-outs/liquidations and advertising errors.

Tractor Supply's Neighbor's Club terms add an important HUNTIQ restriction: resellers are prohibited from extracting, scraping, mining, copying or otherwise collecting Site information in connection with downstream resale activity. HUNTIQ therefore must not build a resale-oriented Tractor Supply web scraper from those public pages.

Implementation consequence: classify Tractor Supply as `restricted research / authorized-data only` for automated collection. Public pages may inform source policy and channel semantics, but any production ingestion should use an expressly authorized feed/API/partnership. If authorized data becomes available later, preserve `storeId`/channel because online and store pricing can differ.

- https://www.tractorsupply.com/tsc/cms/neighbors-club-terms-and-conditions
